# Mini-BK Console 前端

## Summary

为 Mini-BK ResourceOps 搭建 Web 控制台前端，提供任务管理、节点管理和系统监控的可视化界面。

## Goal

提供一个完整的单页应用前端，覆盖任务管理全生命周期（创建、查看、取消、重跑、实时日志）、节点管理（列表、详情、排空/解除）和系统仪表盘。

## Scope

1. **项目脚手架**: Vite + React 19 + TypeScript 6 + Ant Design 5
2. **布局与导航**: 侧边栏菜单 + 路由系统（react-router-dom v7）
3. **仪表盘**: 统计卡片 + 最近任务 + 节点概览
4. **任务管理**: 列表（分页+筛选）、创建（表单+动态节点选择器）、详情（元数据+输出+实时日志流）
5. **节点管理**: 列表（状态筛选+操作）、详情（资源仪表盘+运行任务）
6. **错误处理**: ErrorBoundary + axios 拦截器通知 + 页面级 loading/error/empty 状态
7. **实时日志**: SSE 流式日志展示

## Non-Goals

- 不做用户认证/权限管理
- 不做国际化（仅中文）
- 不做复杂的图表/时间序列可视化

## User-Facing Outcome

1. 浏览器打开 http://localhost:5173 即可访问控制台
2. 仪表盘展示系统概览数据
3. 任务管理覆盖创建 → 查看 → 取消 → 重跑的完整流程
4. 任务详情页支持实时日志流 SSE 推送
5. 节点管理支持在线/离线/排空状态查看和操作

## Acceptance Criteria

| # | 标准 | 验证方式 |
|---|------|----------|
| 1 | `npm run dev` 启动开发服务器 | 浏览器访问显示页面 |
| 2 | `npm run build` 构建成功 | dist/ 目录包含 index.html + assets |
| 3 | 仪表盘加载统计数据、最近任务、节点列表 | 页面渲染无错误 |
| 4 | 任务列表分页+状态筛选正常 | 过滤结果正确 |
| 5 | 创建任务提交后跳转详情页 | 表单校验+API 调用 |
| 6 | 任务详情展示元数据+输出+SSE 实时日志 | 日志实时推送 |
| 7 | 节点列表筛选+排空/解除操作正常 | 操作反馈正确 |
| 8 | API 失败时展示错误通知和错误状态 | 全局 axios 拦截器 + 页面 Result 组件 |
| 9 | 加载中展示 Spin，空数据展示 Empty | 所有列表页覆盖 |
| 10 | ErrorBoundary 捕获渲染异常 | 抛出错误后展示刷新页按钮 |

## Risks

1. **无认证**: API 无鉴权，仅适合内网或本地使用
2. **大 bundle**: Ant Design 5 较大，需关注构建产物大小
3. **SSE 兼容性**: 部分代理环境可能阻断 EventSource 长连接
